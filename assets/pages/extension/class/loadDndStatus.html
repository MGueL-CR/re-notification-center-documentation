loadDndStatus()

loadDndStatus: function () {

        this.isDndOff = this.dndpref.get_boolean("show-banners");
        this.dndItem.setToggleState(!this.isDndOff);
    
        this.blinkIconStopIfBlinking();
        this.manageAutohide();
    
        this.notificationIcon.icon_name = this.notificationIconName;
    
        if(this.isDndOff) {
          this.notificationIcon.set_opacity(255);
          this.manageLabel();
          return false;
        }
     
        if(Gtk.IconTheme.get_default())  {
          if(Gtk.IconTheme.get_default().has_icon("notifications-disabled-symbolic")) {
            this.notificationIcon.icon_name = "notifications-disabled-symbolic";
          }
        }
        else {
          this.notificationIcon.set_opacity(150);
        }
    
        [ this.notificationLabel.visible, this.eventsLabel.visible] = [ false, false ];
        
        return true;
    
      }

Debo decir que con esto acabamos de confirmar varias hipótesis de un solo golpe.

Este método es mucho más rico de lo que esperaba. No solo carga el estado de DND, sino que sincroniza toda la interfaz con ese estado.

Cuando uno lee loadDndStatus() piensa:

"Va a leer el estado."

Pero en realidad hace mucho más. Yo lo renombraría mentalmente como: 

"Sincronizar la interfaz con el estado DND."

Porque eso es exactamente lo que hace.

this.isDndOff = this.dndpref.get_boolean("show-banners");

¡Aquí está el famoso estado! Y además nos revela algo muy interesante, no existe una preferencia llamada: do-not-disturb sino que utiliza: show-banners 

Eso tiene muchísimo sentido, porque GNOME realmente implementa el "No molestar" como:

"¿Mostrar banners?"

Si: show-banners = true Entonces... No molestar está desactivado, por eso la variable se llama: isDndOff

this.dndItem.setToggleState(!this.isDndOff);

Aquí también aprendemos algo, hay un interruptor (toggle) dentro de la extensión y lo pone sincronizado con el estado real.

En un resumen

Si tuviera que resumir loadDndStatus() en una frase sería:

"Sincroniza completamente la interfaz del Notification Center con el estado real del modo No Molestar."

No solo consulta una preferencia, si no que actualiza:

  • el interruptor
  • la campana
  • la opacidad
  • las etiquetas
  • el parpadeo,
  • el autohide

Todo queda coherente con un único estado.
