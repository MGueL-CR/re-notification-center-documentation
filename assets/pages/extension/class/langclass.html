Pero ahora la pregunta es:

¿Qué es NotificationCenter?

¿Hereda de PanelMenu.Button? ¿Hereda de PopupMenu? ¿No hereda de nadie? ¿Es simplemente un objeto que contiene otros objetos?

Eso cambia completamente nuestra comprensión del proyecto.

Lo que espero encontrar

En esa época GJS todavía se utilizaba mucho y creo que veremos algo parecido a:

const NotificationCenter = new Lang.Class({

    Name: 'NotificationCenter',

    _init: function () {

    },

    destroy: function () {

    }

});

Y ya tendríamos identificado el "corazón" de la extensión.

Fíjate en una cosa.

No existe:

constructor()

Existe:

_init()

Y ahí ya podemos hacer una equivalencia mental.
