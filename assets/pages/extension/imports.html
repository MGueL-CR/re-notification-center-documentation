Imports, Constantes y Variables

En las primeras líneas, normalmente ahí encontraremos:

  • imports
  • constantes
  • variables globales

Nada más. La estructura es muy limpia.

const ... 
const ... 
const ... 
 ... 
let notificationCenter = null;

Eso significa que el archivo comienza preparando todo lo que va a necesitar (es una buena práctica.)

Const e Imports

Ahora conozcamos a cada personaje

1. ExtensionUtils

Es el ayudante oficial para las extensiones.

const ExtensionUtils = imports.misc.extensionUtils;

Sirve para cosas como:

  • Obtener la carpeta de la extensión;
  • Obtener información del metadata.json;
  • cargar configuraciones.

Yo lo describiría como:

"La caja de herramientas para extensiones."
2. Gtk

GTK es la biblioteca gráfica. Aquí probablemente se use para las preferencias. Aunque esté importado en extension.js, todavía no sabemos si realmente se utiliza. 

const Gtk = imports.gi.Gtk;
3. Lang.Class 
const LangClass = imports.lang.Class;

Este me llamó inmediatamente la atención. Porque hoy en JavaScript usamos:

class MiClase {
}

Pero hace años GJS no soportaba las clases modernas. Entonces se escribían así:

new Lang.Class(...)

Esto ya nos da una pista enorme. Esta extensión fue escrita con una versión antigua de GJS.

4. Main

Este personaje será uno de los más importantes del proyecto.

const Main = imports.ui.main;

Yo lo definiría así (no literalmente, pero casi):

Main es GNOME Shell.

Desde aquí puedes acceder al:

  • panel superior
  • overview
  • bandeja
  • calendario
  • notificaciones
5. MetaKeyBindingFlags

Meta es el gestor de ventanas de GNOME. Aquí parece que la extensión registra atajos de teclado. Todavía no sabemos dónde, pero ya tenemos una pista.

const MetaKeyBindingFlags = imports.gi.Meta.KeyBindingFlags;
6. PanelMenuButton

Aquí ya apareció algo importante. Este nombre nos dice que la extensión probablemente agrega un botón al panel superior.

const PanelMenuButton = imports.ui.panelMenu.Button;

Sin leer más código ya podemos imaginar algo como:

GNOME Panel
[Actividades]   [Re: Notification Center]
7. PopupMenu

Esto complementa al anterior. Si hay un botón... probablemente exista un menú.

const PopupMenu = imports.ui.popupMenu;
8. ShellActionMode

Esto suele controlar cuándo puede ejecutarse algo.

const ShellActionMode = imports.gi.Shell.ActionMode;

Por ejemplo:

  • escritorio
  • pantalla de bloqueo
  • overview
9. St

Este personaje será nuestro mejor amigo.

const St = imports.gi.St;

ST significa: Shell Toolkit. Es la biblioteca gráfica propia de GNOME Shell. No es GTK y esto es MUY importante.

Muchísima gente confunde esto. Las extensiones NO dibujan el panel usando GTK, lo hacen usando ST. GTK normalmente aparece en las ventanas de preferencias. Este detalle nos ahorrará muchas confusiones más adelante.

Mientras que:

  • panel
  • botones
  • etiquetas
  • iconos

si son ST.

10. util.spawn

Muy interesante. Esto permite ejecutar comandos del sistema.

const utilSpawn = imports.misc.util.spawn;

Algo como:

spawn(["nautilus"]);

O

spawn(["notify-send", "..."]);
11. gettext

Este símbolo: _

const _ = ...

Lo veremos cientos de veces. Sirve para traducciones. Por ejemplo:

_("Preferences")

Dependiendo del idioma del usuario podría mostrar:

Preferencias

0

Settings

Y finalmente...

let notificationCenter = null;

Aquí ya aparece nuestra primera variable global. Todavía no sabemos qué clase será. Pero me gusta una cosa.

No se llama: 
obj
ni 
item

Se llama exactamente igual que la extensión. Eso suele indicar que habrá una clase llamada algo parecido a:

NotificationCenter

Y esta variable contendrá la instancia principal.
