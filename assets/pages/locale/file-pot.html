Portable Object Template — .pot

El archivo: notification-center.pot es la plantilla maestra de traducciones. La idea es:

"Estos son todos los textos que la extensión necesita traducir."

Por ejemplo, imaginemos que el código contiene:

_("Clear")

La herramienta de traducción puede terminar teniendo algo conceptualmente parecido a:

msgid "Clear"
msgstr ""

El .pot contiene los msgid, pero no contiene una traducción específica para un idioma. Por eso se llama:

Portable Object Template

Conceptualmente:

Código de la extensión
        │
        │ textos traducibles
        ▼
notification-center.pot
        │
        ├── alemán
        │     ▼
        │   de/notification-center.po
        │
        ├── italiano
        │     ▼
        │   it/notification-center.po
        │
        ├── coreano
        │     ▼
        │   ko/notification-center.po
        │
        └── neerlandés
              ▼
            nl/notification-center.po

Es una plantilla a partir de la cual se crean los archivos de traducción.
