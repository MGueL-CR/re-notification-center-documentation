Machine Object — .mo

Aquí está la diferencia importante. El .mo es esencialmente la versión compilada/binaria de un .po.

Podemos pensar:

.po
│
│  archivo legible/editable
│
▼
compilación
│
▼
.mo
│
└── archivo binario optimizado

El .po está pensado principalmente para:

  • traductores
  • desarrolladores
  • herramientas de traducción
  • mantenimiento

El .mo está pensado principalmente para:

  • el programa
  • el sistema de traducción en tiempo de ejecución

Por eso normalmente no editamos directamente un .mo.
