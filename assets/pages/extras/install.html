¿Qué es INSTALL.sh?

Este archivo es un instalador auxiliar que prepara un directorio de instalación, elimina una versión previa, copia la extensión y sus recursos (locale y schemas), compila los esquemas GSettings y genera los catálogos binarios de traducción .mo. Finalmente informa al usuario del resultado y le indica que reinicie GNOME Shell y habilite la extensión.

Por tanto, este tipo de archivo no forma parte de una extensión de GNOME, muchas extensiones ni siquiera tienen uno, es simplemente un script que escribió Selenium-H para facilitar la instalación, es una herramienta del proyecto para facilitar la instalación manual. Tampoco, hemos encontrado ninguna razón para considerar INSTALL.sh parte del runtime de RE: Notification Center.

Es decir:

  1. Elimina una versión previa
  2. Copia la carpeta notification-center@Selenium-H y su contenido.
  3. Después complia y copia schemas/ dentro de ella.
  4. Después compila y copia locale/ dentro de ella.

Al final, la extensión instalada queda así:

~/.local/share/gnome-shell/extensions/
        └── notification-center@Selenium-H/
            ├── extension.js
            ├── metadata.json
            ├── ...
            ├── schemas/
            └── locale/

En el contenido del archivo INSTALL.sh nos dirá exactamente cómo el autor esperaba instalar la extensión.

Entonces, ¿por qué el autor lo hizo así?

Creo que fue simplemente una decisión de organización del repositorio, probablemente para mantener separadas las traducciones y los esquemas del código fuente.

No hay ninguna limitación de GNOME que obligue a hacerlo así.
