¿Qué es INSTALL.sh?

Este archivo no forma parte de una extensión de GNOME. Muchas extensiones ni siquiera tienen uno. Es simplemente un script que escribió Selenium-H para facilitar la instalación. En el contenido del archivo INSTALL.sh nos dirá exactamente cómo el autor esperaba instalar la extensión.

La respuesta está aquí:

cp -rf $extensionDir $installDir
cp -rf schemas $installDir"/"$extensionDir
cp -rf locale $installDir"/"$extensionDir

Es decir:

  1. Copia la carpeta notification-center@Selenium-H.
  2. Después copia schemas/ dentro de ella.
  3. Después copia locale/ dentro de ella.

Al final, la extensión instalada queda así:

~/.local/share/gnome-shell/extensions/
        └── notification-center@Selenium-H/
            ├── extension.js
            ├── metadata.json
            ├── ...
            ├── schemas/
            └── locale/

Entonces, ¿por qué el autor lo hizo así?

Creo que fue simplemente una decisión de organización del repositorio, probablemente para mantener separadas las traducciones y los esquemas del código fuente.

No hay ninguna limitación de GNOME que obligue a hacerlo así.
